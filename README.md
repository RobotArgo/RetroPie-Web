# RetroPie-Web
RetroPie-Web is an add-on to a Raspberry Pi 4 running Debian Trixie RetroPie.
The add-on provides a way to access the screen of your Raspberry Pi from another device (ex: Phone, IPad) via a browser. It can also act as a controller for RetroPie

The way it works:
  Step 1: Plug in your Raspberry Pi 4 and wait until it boots into the emulation station screen
  Step 2: Go on your device, select the Wifi settings and select "RetroPie" 
  Step 3: Enter the password "retrogames"
  Step 4: If everything done correctly, it should now be connected. Don't worry if it says "No Internet Connection"
  Step 5: Visit the website 10.42.0.1 on your device
  Step 6: The website should now show the screen of the Raspberry Pi


How to install it:
Run the following commands:

cd ~
unzip -o retropie-web.zip
cd retropie-web
sudo bash install.sh
